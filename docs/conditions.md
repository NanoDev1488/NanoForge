# Условия выполнения (Conditions & If)

Блок **`if:`** позволяет задавать строгие правила выполнения действий или отображения кнопок меню. Если условие не проходит проверку, действие пропускается, а игроку может быть отправлено поясняющее сообщение об отказе (`deny_message`).

---

## 🔍 Поддерживаемые проверки

### 1. Права (Permissions)
```yaml
if:
  permission: "nano.vip"          # Требуется наличие права
  not_permission: "nano.banned"   # Требуется ОТСУТСТВИЕ права
  deny_message: "&cУ вас нет доступа к этой функции!"
```

### 2. Мир и регион WorldGuard
```yaml
if:
  world: "world_nether"           # Только в аду
  region: "spawn_protected"       # Только внутри указанного региона WorldGuard
  deny_message: "&cЭто действие разрешено только на спавне в нижнем мире!"
```

### 3. Баланс экономики (Vault)
```yaml
if:
  eco_at_least: 500               # На балансе должно быть минимум 500 монет
  deny_message: "&cНедостаточно средств! Требуется 500 монет."
```

### 4. Внутренние переменные аддона
```yaml
if:
  var_equals:
    key: "quest_status"
    value: "in_progress"
  var_at_least:
    key: "reputation"
    value: 10
  deny_message: "&cВаша репутация слишком мала или квест не взят!"
```

### 5. Кулдаун (Ограничение по времени)
Ограничивает частоту выполнения действия.
```yaml
if:
  cooldown:
    seconds: 60                   # Раз в минуту
    key: "heal_cooldown"          # Уникальный идентификатор таймера
    scope: player                 # player (у каждого свой) или global (общий на сервер)
  deny_message: "&cПодождите ещё {cooldown} сек. перед повторным использованием."
```
> [!NOTE]
> В `deny_message` автоматически доступен плейсхолдер `{cooldown}`, показывающий точное количество оставшихся секунд. При успешном выполнении кулдаун активируется автоматически.

### 6. Защита от случайных нажатий (Confirm / Двойной клик)
Идеально подходит для необратимых действий (покупка дорогих товаров, удаление данных, сброс прогресса).
```yaml
if:
  confirm:
    seconds: 5                    # Окно ожидания повторного нажатия
    key: "delete_character"
    scope: player
  deny_message: "&eНажмите ещё раз в течение 5 секунд для подтверждения!"
```
* **Как это работает:** Первое нажатие всегда проваливает условие и показывает `deny_message`. Если игрок нажимает на кнопку второй раз в течение `seconds` — действие успешно выполняется.

### 7. Игровое время и онлайн
```yaml
if:
  # Время мира в тиках (0 = рассвет, 6000 = полдень, 12000 = закат, 18000 = полночь)
  time:
    min: 13000
    max: 23000                    # Работает только ночью (корректно поддерживает переход через полночь)
  online_players_at_least: 10     # Только если на сервере онлайн 10+ человек
```

### 8. Окружение: Биомы и Погода
```yaml
if:
  biome_equals: "DESERT"          # Биом под ногами игрока
  weather_equals: "rain"          # clear | rain | thunder
  deny_message: "&cМагия воды доступна только во время дождя в пустыне!"
```

### 9. Группа LuckPerms
```yaml
if:
  luckperms_group: "premium"      # Основная (primary) группа игрока в LuckPerms
  deny_message: "&cТолько для игроков со статусом Premium."
```

## 🔀 Логическая композиция: `any_of`, `all_of`, `not`

Вы можете строить логику любой степени сложности, комбинируя условия:

```yaml
if:
  # Проходит, если игрок админ ИЛИ (имеет баланс 1000 И находится на спавне)
  any_of:
    - permission: "nano.admin"
    - all_of:
        - eco_at_least: 1000
        - region: "spawn"
  # И при этом НЕ находится на кулдауне
  not:
    cooldown:
      seconds: 30
      key: "super_ability"
  deny_message: "&cВы не соответствуете условиям активации суперспособности!"
```

> [!TIP]
> При использовании логических операторов `deny_message` вложенных под-блоков игнорируется, чтобы не спамить в чат множеством сообщений. Игроку выводится только сообщение самого внешнего блока `if:`.

---

## 👁️ Условия видимости в меню

Блок `if:` можно указывать не только у действий `actions`, но и непосредственно у **самого предмета** меню:

```yaml
menus:
  main:
    rows: 1
    items:
      "4":
        material: NETHER_STAR
        name: "&6Секретная кнопка"
        # Предмет появится в слоте ТОЛЬКО если у игрока есть право:
        if:
          permission: "nano.vip"
```

Если условие не выполняется, слот будет казаться игроку пустым. В режиме редактирования (`/nano edit`) администратор видит все предметы независимо от условий.
