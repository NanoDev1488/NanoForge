# Движок действий (Actions Engine)

Действия (**Actions**) — это фундаментальные кирпичики логики NanoForge. Один и тот же набор действий используется в **командах**, **событиях**, **кнопках меню** и **триггерах NPC**.

Каждое действие описывается YAML-объектом с обязательным полем `type:`. Любое действие может содержать необязательный блок условий `if:` (см. [Условия](conditions.md)).

---

## 🎯 Справочник всех 21 типа действий

### 1. `message` — Сообщение игроку
Отправляет форматированное сообщение игроку (или в консоль, если команда вызвана оттуда).
```yaml
- type: message
  text: "&aПривет, &e{player}&a! Твой уровень: &b{level}"
```

### 2. `broadcast` — Объявление на весь сервер
Транслирует сообщение в чат всем онлайн-игрокам.
```yaml
- type: broadcast
  text: "&6★ Игрок &e{player} &6открыл легендарный сундук!"
```

### 3. `console` — Выполнение консольных команд
Выполняет одну команду или список команд от лица серверной консоли.
```yaml
# Одиночная команда:
- type: console
  command: "give {player} diamond 5"

# Пакет команд подряд:
- type: console
  commands:
    - "effect give {player} speed 60 1"
    - "tellraw {player} {\"text\":\"Вам ускорение!\",\"color\":\"green\"}"
```
> [!NOTE]
> Защищено встроенным ограничителем частоты (`ConsoleRateLimiter`, до 100 команд/сек) для предотвращения зацикливания сервера при ошибках в конфигурации.

### 4. `random` — Случайный выбор действия (с весами)
Выбирает и выполняет **ровно одно** действие из предложенного списка с учётом вероятностей (`weight`):
```yaml
- type: random
  actions:
    - weight: 70
      type: message
      text: "&7Обычный приз: деревянный меч"
    - weight: 25
      type: message
      text: "&eРедкий приз: железный меч"
    - weight: 5
      type: message
      text: "&6Легендарный приз: алмазный меч!"
```

### 5. `call` — Вызов метода чужого плагина через рефлексию
Позволяет взаимодействовать с любым плагином на сервере без жесткой зависимости от его API.
```yaml
- type: call
  plugin: CachesManager
  method: reloadDatabaseOnly
  args: []
  save_as: last_db_status     # Сохранить возвращённое значение в переменную аддона
  scope: global               # global или player (по умолчанию player)
- type: message
  text: "&7Результат перезагрузки: &f{result}"
```
* Переданные параметры автоматически приводятся к целевым типам Java (`String`, `int`, `double`, `boolean`, `long`).
* Возвращенное значение доступно в последующих действиях через плейсхолдер `{result}`.

### 6. `openmenu` — Открытие GUI-меню
Открывает инвентарное меню текущего или указанного аддона:
```yaml
# Открыть меню своего аддона:
- type: openmenu
  menu: shop_weapons

# Открыть меню другого аддона:
- type: openmenu
  addon: EconomyHub
  menu: main
```

### 7. `closemenu` — Закрытие инвентаря
Закрывает текущее открытое меню у игрока:
```yaml
- type: closemenu
```

### 8. `setvar` — Сохранение переменной
Записывает строковое или текстовое значение в `storage.yml`:
```yaml
# Переменная конкретного игрока:
- type: setvar
  key: "quest_stage"
  value: "completed"

# Глобальная серверная переменная:
- type: setvar
  key: "total_boss_kills"
  value: "10"
  scope: global
```

### 9. `addvar` — Числовой счётчик (прибавление/вычитание)
Прибавляет число к переменной (для вычитания используйте отрицательные числа):
```yaml
- type: addvar
  key: "coins_collected"
  amount: 25
  scope: player
```

### 10. `eco_give` — Начисление денег (Vault)
```yaml
- type: eco_give
  amount: 250.5
```

### 11. `eco_take` — Списание денег (Vault)
```yaml
- type: eco_take
  amount: 100
```

### 12. `give_item` — Выдача предмета в инвентарь
Выдаёт предмет указанного типа и количества с кастомным названием и лором:
```yaml
- type: give_item
  material: NETHERITE_SWORD
  amount: 1
  name: "&4&lКлинок Бездны"
  lore:
    - "&7Выкован в лавовых озёрах"
    - "&eУрон увеличен"
```
> [!TIP]
> Поля `material` и `amount` поддерживают плейсхолдеры. Например, `material: "{arg1}"`, `amount: "{arg2}"` для команд выдачи.

### 13. `play_sound` — Воспроизведение звука
Проигрывает звук из реестра `org.bukkit.Sound` в локации игрока:
```yaml
- type: play_sound
  sound: ENTITY_PLAYER_LEVELUP
  volume: 1.0
  pitch: 1.5
```

### 14. `sound_stop` — Остановка звука
Останавливает конкретный проигрываемый звук или вообще все звуки:
```yaml
# Остановить конкретный звук:
- type: sound_stop
  sound: MUSIC_DISC_PIGSTEP

# Заглушить все звуки игроку:
- type: sound_stop
```

### 15. `particle` — Эффекты частиц
Спавнит частицы вокруг игрока:
```yaml
- type: particle
  particle: FLAME
  count: 20
  offset_x: 0.5
  offset_y: 1.0
  offset_z: 0.5
  extra: 0.1
```

### 16. `teleport` — Телепортация
Перемещает игрока в указанный мир и координаты:
```yaml
- type: teleport
  world: world_nether
  x: 0.5
  y: 65.0
  z: 0.5
```
*(Если `world` опущен, используется текущий мир игрока).*

### 17. `title` — Заголовки на экране и Action Bar
Отправляет экранный титул (Title), подзаголовок (Subtitle) и/или строку в Action Bar над инвентарем:
```yaml
- type: title
  title: "&6&lПОБЕДА!"
  subtitle: "&7Вы одолели босса"
  actionbar: "&a+1000 очков опыта"
  fadein: 10     # Тики появления (20 тиков = 1 сек)
  stay: 60       # Тики удержания
  fadeout: 20    # Тики затухания
```

### 18. `delay` — Отложенное выполнение (Таймер)
Запускает вложенную цепочку действий спустя указанное количество серверных тиков:
```yaml
- type: message
  text: "&eТелепортация через 3 секунды... Не двигайтесь!"
- type: delay
  ticks: 60
  actions:
    - type: teleport
      x: 100.5
      y: 70.0
      z: 200.5
    - type: message
      text: "&aУспешно телепортирован!"
```

### 19. `discord_webhook` — Отправка логов в Discord
Отправляет сообщение в канал Discord через Webhook. Выполняется **всегда асинхронно** и гарантированно не лагает сервер даже при проблемах с интернетом:
```yaml
- type: discord_webhook
  url: "https://discord.com/api/webhooks/123456789/token"
  content: "🛡️ Игрок **{player}** активировал промокод на сервере!"
```

### 20. `page_next` — Следующая страница меню
Перелистывает текущее динамическое меню игрока на следующую страницу вперед (используется в кнопках GUI):
```yaml
- type: page_next
```

### 21. `page_prev` — Предыдущая страница меню
Перелистывает текущее меню на предыдущую страницу назад:
```yaml
- type: page_prev
```

## 🧩 Доступные плейсхолдеры

### Встроенные плейсхолдеры игрока:
* `{player}` — никнейм игрока
* `{uuid}` — уникальный идентификатор UUID игрока
* `{world}` — имя текущего мира
* `{x}`, `{y}`, `{z}` — округленные целочисленные координаты игрока
* `{health}` — текущее здоровье
* `{level}` — уровень опыта

### Системные и контекстные плейсхолдеры:
* `{result}` — значение, возвращенное предыдущим действием `call`
* `{value}` — значение выбранного элемента в динамическом списке меню (`list:`)
* `{page}` — текущий номер страницы динамического меню (начиная с 1)
* `{maxpage}` — общее количество страниц меню
* `{args}` — все переданные аргументы команды одной строкой
* `{arg1}`, `{arg2}`, `{arg3}`... — позиционные аргументы команды
* `{cooldown}` — количество секунд, оставшихся до завершения кулдауна (доступно в `deny_message`)

### Интеграция с PlaceholderAPI:
Если на сервере установлен плагин **PlaceholderAPI**, абсолютно любые внешние плейсхолдеры (например `%vault_eco_balance%`, `%luckperms_primary_group%` и т.д.) работают автоматически во всех текстовых полях!
