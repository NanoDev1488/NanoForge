# GUI-меню и внутриигровой редактор

NanoForge включает встроенную систему инвентарных меню (GUI) с поддержкой неограниченной вложенности, анимаций через переходы, условий видимости и **визуального редактора прямо в игре**.

---

## 📦 Описание меню в `addon.yml`

Каждое меню описывается в секции `menus:` вашего аддона:

```yaml
menus:
  main:
    title: "&8★ Главное меню сервера ★" # Заголовок инвентаря (поддерживает цветовые коды &)
    rows: 3                            # Количество строк (от 1 до 6, т.е. от 9 до 54 слотов)
    items:
      "11":                            # Номер слота (отсчёт начинается с 0)
        material: DIAMOND_SWORD        # Материал предмета из реестра Bukkit
        amount: 1                      # Количество (по умолчанию 1)
        name: "&b&lНабор Воина"        # Название предмета
        lore:                          # Описание (список строк)
          - "&7Нажмите, чтобы получить"
          - "&7базовый комплект экипировки."
          - ""
          - "&aСтоимость: &f100 монет"
        actions:                       # Список действий при клике по предмету
          - type: eco_take
            amount: 100
            if:
              eco_at_least: 100
              deny_message: "&cНедостаточно монет для покупки набора!"
          - type: give_item
            material: IRON_SWORD
          - type: message
            text: "&aВы успешно приобрели экипировку!"

      "15":
        material: CHEST
        name: "&eПерейти в подменю"
        actions:
          - type: openmenu
            menu: sub_category         # Открывает вложенное меню

      "26":
        material: BARRIER
        name: "&c✖ Закрыть"
        actions:
          - type: closemenu
```

## 🎨 Визуальный редактор в игре: `/nano edit`

Вам больше не нужно вручную подбирать названия материалов или форматировать длинные строки лора в текстовом редакторе!

### 1. Режим Drag-and-Drop (Перетаскивание предметов)
Выполните команду:
```shell
/nano edit <аддон> <меню>
```
* Меню откроется в особом режиме редактирования (с пометкой `[Edit]` в заголовке).
* Возьмите **любой предмет** из своего инвентаря и просто перетащите его в желаемый слот меню.
* **NanoForge автоматически сохранит:**
  * Материал предмета.
  * Количество.
  * Отображаемое имя (Display Name).
  * Полный лор (Lore) с сохранением всех цветов.
* Изменения **мгновенно записываются** в `addon.yml`, а перед этим в папку `backups/` создаётся резервная копия на случай ошибки.

---

### 2. Настройка логики кликов через чат-DSL (Shift + Клик)
Чтобы настроить, что происходит при нажатии на предмет:
1. В режиме редактирования `/nano edit` нажмите **Shift + Левый клик** по предмету в меню.
2. Меню закроется, и плагин переведёт вас в интерактивный режим чата.
3. Вводите действия одной строкой по специальному простому синтаксису:

| Синтаксис команды в чате | Что делает действие |
|---|---|
| `message <текст>` | Отправляет сообщение кликнувшему игроку |
| `broadcast <текст>` | Объявление на весь сервер |
| `console <команда>` | Выполнить команду от консоли |
| `call <плагин> <метод> [аргументы]` | Вызвать метод другого плагина через рефлексию |
| `openmenu <меню> [аддон]` | Открыть другое меню (подменю) |
| `closemenu` | Закрыть меню |
| `setvar <ключ> <значение> [global]` | Сохранить переменную аддона |
| `addvar <ключ> <число> [global]` | Прибавить число к переменной |
| `eco_give <число>` | Начислить монеты игроку (Vault) |
| `eco_take <число>` | Списать монеты у игрока (Vault) |

* Вы можете ввести несколько действий подряд — они добавятся в цепочку по порядку.
* Чтобы сохранить результат и вернуться к меню, напишите в чат: `done`.
* Чтобы отменить ввод, напишите: `cancel`.

## 👁️ Условия видимости предметов (`if:`)

Вы можете скрывать определенные кнопки от обычных игроков, показывая их только избранным:

```yaml
items:
  "22":
    material: GOLD_INGOT
    name: "&6Панель администратора"
    if:
      permission: "nano.admin"
    actions:
      - type: openmenu
        menu: admin_panel
```

* **В обычной игре (`/nano menu`):** Игрок без права `nano.admin` увидит пустой слот.
* **В режиме редактирования (`/nano edit`):** Администратор всегда видит все предметы, чтобы их можно было редактировать независимо от условий видимости.
