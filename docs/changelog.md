## 🌟 Версия 1.6.0 *(Текущая)*

### 🧙 Интерактивный GUI-визард (`/nano wizard`)
* **Создание аддона кликами:** Теперь не нужно печатать команды вручную или править YAML с нуля:
  1. Меню выбора типа: «Мини-плагин» (`type: new`) или «Аддон к плагину» (`type: addon`).
  2. При выборе аддона открывается постраничный визуальный список **всех реально загруженных плагинов сервера** (с пагинацией).
  3. Ввод имени в чате с автоматической валидацией.
  4. Автоматическая генерация файлов, дампинг `target-api.txt` и подсказка дальнейших действий (`/nano edit`, `/nano enable`).

### 📦 Дедупликация и чистота кода:
* Добавлен универсальный модуль `ItemBuilder` для конструирования предметов с кастомными цветами и описаниями.
* Полный стек юнит-тестов увеличен: **255/255 тестов успешно пройдено**.

## 🚀 Версия 1.5.0

### 📄 Динамические списки и пагинация в GUI (`list:`)
* Меню теперь могут автоматически генерировать слоты из динамических списков:
  * Источник `source: online_players` (список онлайн-игроков с автоматической раскладкой по слотам `slots_from` — `slots_to`).
  * Новые плейсхолдеры: `{value}` (значение элемента списка), `{page}` и `{maxpage}` в заголовках.
  * Новые действия перелистывания: `page_next` и `page_prev` для листания страниц текущего меню.

### 🔌 Оптимизация кэширования плагинов
* Новый модуль `PluginPresenceCache`: централизованное и быстрое кэширование факта установки сторонних плагинов (WorldGuard, LuckPerms, Citizens) без повторных тяжелых поисков.

### 🛡️ Интеграция с Citizens & NPC триггеры
* Секция `npcs:` в `addon.yml` — привязка действий к жителям по их `npc_id` без Java-кода.
* Единая сводка зависимостей (Startup Health-Check) в консоли при включении сервера со ссылками на скачивание недостающих плагинов.

## ⚡ Версия 1.4.0 – 1.3.0

* **Логические операторы в `if:`** — поддержка `any_of` (ИЛИ), `all_of` (И) и `not` (НЕ) любой глубины вложенности.
* **Новые условия:** проверка биома под ногами (`biome_equals`), погоды (`weather_equals`), группы LuckPerms (`luckperms_group`).
* **Новые действия:**
  * `random` с весами вариантов (`weight`).
  * `sound_stop` — остановка конкретного звука или всех сразу.
  * `discord_webhook` — асинхронные HTTP POST запросы в каналы Discord без просадки TPS.
  * Мультикоманды в `console` через список `commands: [...]` с ограничителем частоты `ConsoleRateLimiter`.
* **Инструменты разработчика:**
  * `/nano validate` — аудит сразу всех аддонов.
  * `/nano diff <аддон>` — сравнение изменений файла на диске с памятью до перезагрузки.
  * `/nano debug <аддон>` — подробный лог выполнения каждого действия в реальном времени.
  * Автобэкапы `addon.yml` в папку `backups/` (хранит до 20 последних версий).

## 🛠️ Версия 1.0.0 – 1.0.1

* Первая стабильная публичная версия:
  * Двупроходная загрузка аддонов с поддержкой зависимостей `requires: [...]`.
  * Динамический `CommandMap` и синхронизация Brigadier (`syncCommands`).
  * Target Inspector: автодамп API целевых плагинов в `target-api.txt`.
  * Визуальный Drag-and-Drop редактор меню (`/nano edit`) и чат-DSL для настройки кнопок.
  * Мягкие мосты к Vault, WorldGuard, PlugMan.
  * Полная совместимость со Spigot / Paper от 1.16 до 1.21.x на байткоде Java 8.
