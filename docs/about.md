# Что такое NanoForge простыми словами?

<div align="center">

> **Главное заблуждение:** NanoForge — это **НЕ** загрузчик модов Minecraft Forge!  
> Это **плагин для обычных серверов** (Paper, Purpur, Spigot 1.16–1.21), клиентам игроков **не нужно ничего устанавливать**.

</div>

---

## 🛑 Какую проблему решает NanoForge?

Каждый владелец сервера Minecraft, тех-админ или создатель сборок сталкивается с одной и той же головной болью:

1. **Вечная нехватка мелких функций:** В установленном плагине (например, плагине кланов, магазине или экономике) нет нужной вам команды или красивого инвентарного меню. Ради одной кнопки приходится либо просить разработчика, либо искать сомнительные аддоны, либо писать свой Java-плагин.
2. **Сложность разработки:** Чтобы написать даже крошечный плагин на 20 строк, нужно:
   * Установить JDK, среду разработки (IntelliJ IDEA), настроить сборщик (Maven/Gradle).
   * Разобраться в Bukkit API и классах сторонних плагинов.
   * Каждый раз компилировать `.jar`, загружать его на сервер через SFTP, перезагружать сервер или использовать релоадеры, рискуя утечками памяти.
3. **Монструозность скриптовых движков (Skript):** Популярные скриптовые плагины часто тяжелы, имеют непредсказуемый синтаксис, могут сильно тормозить TPS и ломаются при обновлениях ядра сервера.
4. **Зоопарк плагинов на одно действие:** Для меню ставят *DeluxeMenus*, для команд — *MyCommand*, для NPC — костыли через консоль, для проверки прав — ещё три прослойки. В итоге сервер забит десятками плагинов, каждый из которых работает по-своему.

---

## 💡 NanoForge как решение: "Универсальный клей и конструктор"

**NanoForge — это ваш встроенный инструмент разработки без кода и компилятора.**

Представьте, что внутри вашего сервера появился инструмент, который умеет:
* **На лету создавать новые команды** (они сразу регистрируются в сервере и автоматически подсвечиваются у игроков в чате благодаря Brigadier).
* **Слушать любые события игры** (вход игрока, смерть, клик по NPC, открытие сундука).
* **Создавать красивые интерактивные меню**, которые можно настраивать прямо из игры перетаскиванием предметов из своего инвентаря.
* **Связываться с любым другим плагином на сервере** и вызывать его внутренние функции напрямую — даже если разработчик того плагина не делал команду для этого!

И всё это описывается в простом, понятном YAML-файле или настраивается командами в игре **без единой перезагрузки сервера**.

## 🆚 Сравнение с альтернативами

| Задача / Возможность | Обычный Java-плагин | Skript | Набор DeluxeMenus + MyCommand | **NanoForge** |
|---|---|---|---|---|
| **Нужно знать Java и IDE?** | Да, обязательно | Нет (свой псевдо-язык) | Нет | **Нет, простой YAML / игра** |
| **Нужна компиляция jar?** | Да, каждый раз | Нет | Нет | **Нет, редактируется на лету** |
| **Вызов методов других плагинов** | Нужны зависимости в pom.xml | Сложно / через аддоны | Не умеет | **Встроенный `call` через рефлексию** |
| **Шпаргалка по методам плагина** | Искать декомпилятор | Нет | Нет | **Автодамп `target-api.txt`** |
| **Редактор меню прямо в игре** | Нет | Нет | Ограниченно | **Drag-and-Drop + Чат-DSL** |
| **Влияние на производительность** | Высокая | Может просаживать TPS | Средняя | **Максимальная (чистый Bukkit)** |
| **Безопасность при ошибках** | Сервер падает / спамит стек | Спамит ошибки | Ошибки парсинга | **Изолированный перехват + бэкапы** |

## 🎯 Реальные жизненные сценарии: для чего его используют?

### Сценарий 1: "Хаб управления другим плагином"
> *У вас стоит сложный плагин `CachesManager` или `ClanSystem`. Чтобы перезагрузить отдельную базу данных или выдать награду, создателю плагина лень было делать отдельные команды.*
* **Как решает NanoForge:** Создаём аддон `/nano create addon CachesManager MyHub`. NanoForge сам сканирует jar-файл плагина и кладёт файл `target-api.txt`. В нём видно метод `reloadDatabaseOnly()`. В меню одной строчкой пишем `type: call, plugin: CachesManager, method: reloadDatabaseOnly`. Готово! Кнопка в меню теперь дёргает внутренний код плагина.

### Сценарий 2: "Единое меню наград и магазинов"
> *Нужно меню, где VIP-игроки могут забирать бонус раз в 24 часа с красивым подтверждением двойным кликом, а обычные игроки видят сообщение с требованием купить донат.*
* **Как решает NanoForge:** Меню создаётся за пару минут. Задаётся предмет, на него вешается условие `cooldown: 86400`, защита от случайного клика `confirm: 5` и выдача награды через `eco_give` или `give_item`.

### Сценарий 3: "Умный NPC с квестом или магазином"
> *Стоит плагин Citizens. Вы хотите, чтобы при клике по NPC-кузнецу проверялось наличие 500 монет и уровня 10, после чего чинился предмет в руке и играл звук.*
* **Как решает NanoForge:** В секции `npcs:` прописываем ID жителя, условия `eco_at_least: 500` и список действий (`eco_take`, `play_sound`, `title`, `console`). Никаких лишних плагинов-костылей.

## 🧭 Как устроен NanoForge изнутри?

1. **Движок действий (Actions):** 19 встроенных действий от выдачи предметов и проигрывания звуков до асинхронных вебхуков в Discord и задержек `delay`.
2. **Движок условий (Conditions):** Мощнейшая система условий `if:`, поддерживающая `any_of` (ИЛИ), `all_of` (И), `not` (НЕ), проверку регионов WorldGuard, баланса Vault, групп LuckPerms, погоды, времени и биомов.
3. **Хранилище переменных:** Встроенное хранилище `storage.yml` помнит данные игроков (переменные, балансы, этапы квестов, кулдауны) без необходимости подключать MySQL.
4. **Инспектор кода (Target Inspector):** При создании аддона NanoForge сам изучает целевой плагин и подсказывает, какие функции у него есть.
