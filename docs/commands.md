# Команды и управление

Для администрирования NanoForge используется корневая команда `/nano` (также доступны алиасы `/nanoforge` и `/nd`).

> [!IMPORTANT]
> Для выполнения команд управления требуется право: `nano.admin` (по умолчанию доступно операторам сервера).  
> Команды, зарегистрированные внутри самих аддонов, настраиваются отдельно через `permission` в `addon.yml`.

---

## 📋 Справочник команд `/nano`

| Команда | Описание |
|---|---|
| `/nano wizard` | Интерактивный пошаговый GUI-визард создания аддона в игре |
| `/nano create addon <плагин> <имя>` | Создать аддон к установленному плагину с автоматическим дампом API |
| `/nano create new <имя>` | Создать независимый автономный мини-плагин |
| `/nano enable <имя>` | Включить аддон и зарегистрировать его команды, события и меню |
| `/nano disable <имя>` | Выключить аддон и снять все регистрации из Bukkit |
| `/nano list` | Показать список всех аддонов с их типами и статусом |
| `/nano info <имя>` | Подробная информация: целевой плагин, команды, события, меню, зависимости |
| `/nano reload` | Полная перезагрузка всех аддонов с диска без рестарта сервера |
| `/nano menu <аддон> <меню>` | Открыть указанное инвентарное меню игроку |
| `/nano edit <аддон> <меню>` | Открыть меню в режиме визуального редактирования |
| `/nano duplicate <аддон> <новое_имя>` | Сделать полную копию существующего аддона |
| `/nano export <аддон>` | Упаковать аддон в `.zip`-архив в `plugins/NanoForge/exports/` |
| `/nano import <файл.zip> <имя>` | Импортировать аддон из `plugins/NanoForge/imports/` |
| `/nano vars <аддон>` | Показать текущие глобальные переменные аддона (для отладки) |
| `/nano validate [аддон]` | Аудит одного аддона или **всех сразу** на ошибки конфигурации |
| `/nano get <аддон> <путь>` | Посмотреть значение по YAML-пути (с табкомплитом по ключам) |
| `/nano set <аддон> <путь> <значение>` | Изменить скалярное значение в `addon.yml` с автобэкапом |
| `/nano diff <аддон>` | Сравнить текущую версию в памяти с изменениями в файле на диске |
| `/nano debug <аддон>` | Включить/выключить подробный лог выполнения каждого action в консоль |
| `/nano update` | Проверить и скачать обновление плагина с GitHub Releases |

## 🛠️ Подробный разбор ключевых команд

### 0. Интерактивный мастер создания: `/nano wizard`
Самый простой способ создать аддон прямо в игре без необходимости помнить аргументы команд:
1. Выполните `/nano wizard`.
2. Выберите в открывшемся GUI тип: «Мини-плагин» или «Аддон к плагину».
3. Если выбран аддон к плагину — выберите нужный плагин из постраничного списка реально включенных на сервере плагинов (с кнопками «Вперёд» / «Назад»).
4. Напишите желаемое имя аддона в чат.
5. Аддон автоматически создастся, сгенерирует `target-api.txt` и предложит открыть его меню или редактирование!

### 1. Быстрое изменение параметров: `/nano set` и `/nano get`
Вам не обязательно открывать файл конфигурации через FTP или текстовый редактор ради изменения одного параметра:
```shell
# Посмотреть текущее название предмета:
/nano get MyAddon menus.main.items.11.name

# Изменить название предмета прямо из чата:
/nano set MyAddon menus.main.items.11.name &6Новое_Название
```
* **Умный Tab-Complete:** При нажатии клавиши `Tab` после указания пути команда автоматически подставит **текущее значение**. Вы можете изменить одну букву или цифру без необходимости перепечатывать строку заново.
* **Безопасность:** Перед изменением файла NanoForge автоматически создаст резервную копию в папку `backups/`.
* Применение изменений: после команды выполните `/nano reload`.

---

### 2. Валидация и аудит: `/nano validate`
Статическая проверка конфигурации без необходимости её выполнения:
* **Проверка конкретного аддона:**
  ```shell
  /nano validate MyAddon
  ```
  Проверяет:
  * Корректность материалов по реестру Bukkit (с учётом регистра).
  * Корректность номеров слотов относительно размера меню (`rows * 9`).
  * Ссылки на несуществующие меню в действиях `openmenu`.
  * Неизвестные типы действий и синтаксические опечатки в `type`.
  * Резолв классов событий в стандартных пакетах Bukkit.

* **Массовый аудит всех аддонов:**
  ```shell
  /nano validate
  ```
  Выводит сводный отчёт по всей серверной инфраструктуре аддонов с подсчётом ошибок и предупреждений.

---

### 3. Сравнение изменений: `/nano diff`
Если вы отредактировали `addon.yml` вручную через текстовый редактор и хотите понять, что изменится после перезагрузки:
```shell
/nano diff MyAddon
```
NanoForge построчно сравнит активную конфигурацию в памяти сервера с версией файла на диске и выведет добавленные, изменённые или удалённые параметры.

---

### 4. Трассировка в реальном времени: `/nano debug`
```shell
/nano debug MyAddon
```
Включает verbose-лог для конкретного аддона. При каждом клике по кнопке, вызове команды или срабатывании события в консоль сервера будет выводиться подробная информация:
* Какой именно action сейчас исполняется.
* От лица какого игрока.
* Прошло ли условие `if` или было отклонено.
* Каков результат вызова рефлексии `{result}`.

> [!NOTE]
> Debug-режим хранится только в оперативной памяти и автоматически сбрасывается при перезагрузке сервера.

## ⚡ Динамические команды аддонов

Каждая команда, объявленная в секции `commands:` аддона, является полноценной командой сервера:

```yaml
commands:
  guild:
    description: "Меню гильдий"
    permission: myguild.use
    actions:
      - type: openmenu
        menu: guild_main
```

### Особенности работы:
1. **Регистрация без `plugin.yml`:** Команда регистрируется напрямую во внутреннем `CommandMap` Bukkit'а.
2. **Мгновенная синхронизация Brigadier:** На версиях Minecraft 1.13+ клиент игры кэширует список доступных команд. NanoForge вызывает `CraftServer#syncCommands()`, благодаря чему новые команды мгновенно подсвечиваются в таб-комплите у всех подключённых игроков без необходимости перезахода.
3. **Изоляция исключений:** Если внутри команды аддона возникнет ошибка (например, кривой параметр стороннего плагина), NanoForge перехватит её, уведомит администратора в консоли и не позволит серверу выдать уродливый красный стек-трейс игроку.
